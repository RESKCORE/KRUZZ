## Reporting a Vulnerability

We take the security of KRUZZ and its users seriously. If you discover a security vulnerability, please do NOT open a public GitHub issue.

Instead, please report security vulnerabilities via GitHub's Private Vulnerability Reporting feature:

1. Navigate to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide a detailed summary, proof of concept, and affected components.

Alternatively, contact the maintainers directly through GitHub.

We will acknowledge receipt within 48 hours and provide updates until the issue is addressed.
