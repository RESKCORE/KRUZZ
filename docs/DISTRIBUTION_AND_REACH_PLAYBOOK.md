- **Timing**: Tuesday, Wednesday, or Thursday at **8:00 AM – 9:30 AM ET (12:00 PM – 1:30 PM UTC)**.
- **URL**: `https://kruzz.indevs.in` (or link directly to GitHub `https://github.com/RESKCORE/KRUZZ`)

### Title Options (Pick One)

> **Option 1 (Recommended)**:  
> `Show HN: KRUZZ – Interactive Real-World System Architecture Case Studies`

> **Option 2**:  
> `Show HN: We built an open-source platform to learn distributed systems backwards`

### First Comment (Post immediately within 60 seconds of submitting)

```markdown
Hey HN!

Most system design tutorials start with abstract box-and-arrow diagrams or jump straight into high-level buzzwords ("use a distributed cache and Kafka!"). But for students and junior engineers, there is an immense disconnect between writing basic code and understanding _why_ an architectural pattern needs to exist.

We built KRUZZ (https://kruzz.indevs.in) to reverse this learning order:

Real-World Crisis / Incident → Context → System Component Breakdown → Engineering Invariants → Progressive Architecture Diagrams (Mermaid) → Trade-off Decisions → Multi-Language Code Ladder → Interactive Code Arena with AI Evaluation.

Key Highlights:

1. 35 Curated Case Studies: From basics (ATM machine, client-server, DNS lookup) to advanced distributed systems (Consistent Hashing Shard Rings, Two-Phase Commit, Quorum Reads/Writes, Partitioned Event Streaming, Circuit Breakers).
2. Progressive Architecture: Diagrams are revealed level by level (Topology → Component Flow → Failure/Resiliency Path) rather than dumped all at once.
3. System Design Roadmap: A 400-line production reference covering CAP theorem, latency numbers every engineer must know, routing, and consensus.
4. Open Source: Built with TanStack Start, React 19, TypeScript, and Convex.

Repository: https://github.com/RESKCORE/KRUZZ

We’d love feedback from the HN community on:

- How clear the architectural trade-off breakdowns feel
- What real-world systems you would like to see added to the curriculum
```

#### B. `r/learnprogramming` & `r/csMajors`
